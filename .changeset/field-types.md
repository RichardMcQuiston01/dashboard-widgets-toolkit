Field types for table columns. A `TABLE` column can set `type` to `email` (a `mailto:` link; display names, lists and `?cc=` style parameters are refused), `url` (an absolute http(s) link that opens in a new tab with `rel="noopener noreferrer"`), `image` (an `<img>` with the cell text as alt text, through `isSafeImageUrl`), `color` (a swatch beside the text, `#rgb` or `#rrggbb`) or `custom`. A cell reads the address, URL or color from a string `value`, else its `text`; a value the type can't use shows the text. `custom` columns name a `formatter` you register with `WidgetSettingsProvider`'s `formatters` (`CellFormatter`), with `onFormatterError` for a missing or failing one, and the cell's text stays as visually hidden text. Types carry over to the detail view and work with search and sort, which keep using `text` and `value`. Core: `cellField`, `isSafeEmail`, `isSafeWebUrl`, `isSafeCellColor`, `validateFormatters` and the field checks in `validateWidgetData` and `validateDetailData`. React: `CellContent`, `NewTabIndicator` (the new-tab icon, now shared with `WidgetLink`), and an optional `widgetKey` on `WidgetContent`, `TableWidget` and `WidgetDetail`.
